# VaaniDesk AI — measured results

Measured on 31 Oct 2026, one laptop (8 CPUs, no GPU), shared Neon database (US East).
All customers and data are synthetic. Test audio is generated by neural TTS voices, which is cleaner
than real callers; real recordings from the team should be added before claiming field accuracy.

## What runs where

| Step | Technology | LLM? |
|---|---|---|
| Speech-to-text | Whisper `base.en` (faster-whisper, local CPU, int8) + banking vocabulary prompt | No |
| Intent + details | Rule-based NLU (`app/nlu.py`). Claude support is coded but **not enabled or measured** | No |
| Verification, routing, escalation | Deterministic Python rules | No |
| Replies | Templates filled only from database values + number check | No |
| Speech output | Browser speech synthesis | No |

## 1. Conversation tests (text, 15 scenarios, real Neon data)

`EVAL_BACKEND=neon python -m tests.run_eval` → **15 / 15 passed**

Covers: two questions in one sentence, verification, 3 failed attempts → lock + handoff, someone else's data refused,
fee waiver refused, fraud complaint → HIGH escalation, unknown request → fallback ticket, "which loan?" + correction,
overdue vs upcoming EMI, ticket status, pending transaction (no guessed cause), claim under review (no promise), FAQ with source,
"talk to a human", no data before verification.

## 2. Speech understanding (180 clips)

9 phrases × 4 voices (Indian female, Indian male, US male, UK female) × 5 conditions.
"Understood" = the agent extracted the expected intents and details from Whisper's transcript.

| Condition | Understood | Mean WER | Mean STT time |
|---|---|---|---|
| Clean | 36 / 36 | 0.09 | 1.8 s |
| Busy room (light noise) | 36 / 36 | 0.09 | 1.8 s |
| Street / crowd (loud noise) | 36 / 36 | 0.09 | 1.8 s |
| Phone line (8 kHz, narrow band) | 32 / 36 | 0.11 | 1.8 s |
| Fast speech + noise | 34 / 36 | 0.10 | 1.8 s |
| **All** | **174 / 180 (97%)** | | |

Remaining misses: "never made" heard as "never need" (3, phone/fast), date of birth on phone audio (2),
"personal loan" heard as "person alone" (1, fast US voice). Before the domain prompt + customer-ID fix: 166 / 180.
WER is inflated by number formatting ("C 1 0 2 3" vs "C1023").

## 3. Full voice call through the app (frontend → server → AI → Neon)

| Caller audio | Agent result |
|---|---|
| Status + first EMI (loud noise, Indian male) | Asks for customer ID |
| "Customer ID is C1023" (phone, heard "T1023") | Correctly reads C1023, asks DOB |
| DOB (light noise, UK) | Verified; "awaiting document verification, not approved yet" |
| Repayment schedule (fast, US) | Ticket SR-4489 |
| "A debit I never made" (loud, UK) | Complaint CMP-2216 + HIGH escalation, visible in ops escalation queue |

Per-turn time, voice, end to end: **4.7 – 7.5 s**. Of that, speech-to-text ≈ 1.8 s and AI processing ≤ 0.3 s
(profile loaded once per call); the rest is server-side database writes to the US-region database.

## Known limits

- No LLM in use. Intent detection is rule-based; phrasing far from the rules goes to the "unknown" fallback.
- English only (Whisper `base.en`).
- Synthetic voices only; no real-caller recordings measured yet.
- Voice turn latency above target (~5 s) mainly from cross-region database round trips.
